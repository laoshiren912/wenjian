# 问剑

《问剑》是一款使用 Godot 4 制作的像素仙侠动作肉鸽原型。操纵剑修闯关、击败敌人，选择功法并挑战最终首领。

## 在线试玩

[在 itch.io 游玩《问剑》](https://laoshiren912.itch.io/wenjian)

## 操作说明

- **W / A / S / D**：移动
- **鼠标**：瞄准
- **鼠标左键**：普通攻击三连
- **鼠标右键**：掷剑
- **空格**：垫步
- **E**：万剑归宗
- **Tab**：查看属性
- **Esc**：暂停

## 本地运行

使用 Godot 4.x（项目开发使用 Godot 4.7.2）打开根目录的 `project.godot`，导入资源后运行项目。
