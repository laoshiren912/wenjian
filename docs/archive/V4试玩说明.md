# V4 最小 Roguelite 循环试玩

Godot 4.7.2 打开根目录 project.godot，按F5，直接进入第1个战斗房间。
WASD移动，鼠标瞄准，左键逐次点击三段剑击，右键弓，Space翻滚，Tab属性，Esc暂停。
旧V3.3仍可打开 `scenes/main_v33.tscn` 按F6对照；本轮没有修改其战斗动作和基础参数。

## 一局流程

第1间（3近战）→领奖→第2间（3近战1远程）→领奖→第3间（4近战1远程）→领奖→终点通关。
三个房间复用同一通道形状，进入下一间后人物回到左侧，HUD房间编号变化，敌人重新出现。

## 请手动检查

1. **开场与战斗**：第1间有3只近战；后两间分别共4/5只，其中各1只远程。确认剑弓、翻滚、敌人追击/攻击仍正常；战斗未完成不能从右侧离开。
2. **清房与领取**：最后一只死亡后，中央出现一个金色菱形奖励。远离它时不弹窗；靠近后暂停并显示三选一。此时Esc/Tab不能跳过，只有选择一项才能继续。
3. **出口条件**：清场但未领奖时出口外圈变金色，仍不能换房；领奖后奖励消失、出口变绿色，走进去才能切到下一间。返回奖励位置不能再次领取。
4. **奖励数值**：用Tab看属性。剑伤选一次应为36.8/46.0/69.0，弓仍21；再选一次剑伤应为41.6/52.0/78.0。生命奖励使上限和当前生命各加20；翻滚冷却选一次由0.650变为0.553秒（显示取三位小数）。
5. **跨房保留**：受伤后记下生命，领奖再换房，确认换房本身没有回血，已领奖励继续有效。体力保留，但会按原有规则自然恢复；换房重置临时动作与冷却。
6. **死亡重开**：在第2或第3间死亡，结算应显示所在房间和本局击杀数。分别试R、Enter或按钮，均回第1间，生命/体力恢复100，奖励清空，剑伤恢复32/40/60、翻滚冷却恢复0.650秒。
7. **暂停与界面**：Esc/Tab打开和关闭正常，世界暂停；点击UI不挥剑。暂停菜单“重新开始”也应清空整局，而非只重置当前房间。
8. **通关与重开**：第三次清场仍需领奖，再进出口，到达无怪的终点房间并显示通关、本局12次击杀。重开回第1间，奖励清空。
