## 测试隔离方式

`scripts/test_runtime.gd` 只在以下条件同时满足时允许内部状态注入：引擎为 debug 构建，且当前 SceneTree 由资源路径位于 `res://tests/` 的主测试脚本驱动。

普通 F5、普通 debug 导出、Release/Web 导出均不能仅凭 debug 构建、headless、项目设置或键盘组合启用。没有新增运行时开关、命令行解锁参数或 Autoload。Web 预设继续排除 `tests/` 与 `artifacts/`。

源码保留测试夹具所需函数，属于禁用正式入口，而非删除所有历史测试代码。修改源码、重新打包或显式运行仓内测试脚本不属于普通游玩的误触范围。
