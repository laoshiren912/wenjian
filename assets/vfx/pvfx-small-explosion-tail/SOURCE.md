# PVFX Foundry 1.1.0

https://nerijs.itch.io/pvfx-foundry

Small Explosion, Lit grid, source frames 10–14 (one-based), 64×64 per frame, 60 ms each. The strip preserves the source RGBA pixels in their original order. Source ground pivot (32, 57). Original license included.

The local smoke animation uses smoke-strip-light.png, a separate neutral grayscale lift of this strip with unchanged alpha. The original extracted smoke-strip.png is preserved. The game plays the five frames at 10 FPS.
